# @your-org/buttons

Reusable Button components for React (Primary, Secondary, Danger, Outline, etc.)

## Installation

```sh
npm install @your-org/buttons
```

## Usage

```tsx
import { PrimaryButton, DangerButton } from '@your-org/buttons';

<PrimaryButton onClick={() => alert('Clicked!')}>Click me</PrimaryButton>
```

## Available Exports
- PrimaryButton, PrimaryButtonSmall, PrimaryButtonLarge, PrimaryButtonXSmall
- PrimaryOutlineButton, PrimaryOutlineButtonSmall, PrimaryOutlineButtonLarge, PrimaryOutlineButtonXSmall
- SecondaryButton, SecondaryButtonSmall, SecondaryButtonLarge, SecondaryButtonXSmall
- SecondaryOutlineButton, SecondaryOutlineButtonSmall, SecondaryOutlineButtonLarge, SecondaryOutlineButtonXSmall
- DangerButton, DangerButtonSmall, DangerButtonLarge, DangerButtonXSmall
- DangerOutlineButton, DangerOutlineButtonSmall, DangerOutlineButtonLarge, DangerOutlineButtonXSmall
