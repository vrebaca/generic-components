# @vrebaca/typography

Typography components using styled-components for consistent text styles.

## Usage

```tsx
import { H1Regular, H2SemiBold, TextBodyMdRegular } from '@fiskaltrust/typography';

<H1Regular>Heading 1</H1Regular>
<TextBodyMdRegular>Body text</TextBodyMdRegular>
```

## Publishing
This package is configured for GitHub Packages. To publish:

1. Build your package (if needed).
2. Run:
   ```sh
   npm publish --access public
   ```
